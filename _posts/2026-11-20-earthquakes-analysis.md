## Introducción

Este proyecto analiza la actividad sísmica registrada durante un año a partir de datos obtenidos mediante API.

El objetivo es estudiar la distribución espacial de los terremotos, identificar patrones y generar visualizaciones que faciliten la interpretación de los datos.

## Tecnologías utilizadas

- Python
- Pandas
- GeoPandas
- SQLite
- Power BI
- Matplotlib
- Seaborn

## Obtención de datos

Los datos fueron obtenidos a través de una API pública de actividad sísmica.

## Procesamiento

El flujo de trabajo incluyó:

1. Extracción de datos.
2. Limpieza y transformación.
3. Almacenamiento en SQLite.
4. Análisis exploratorio.
5. Visualización de resultados.
